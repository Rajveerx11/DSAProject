Operation explanations arrive with the state.

    These are explanatory steps from the backend, not instruction-level debugging. Boundary navigation stops; it never wraps.

    A ten-minute spin through the DSA lab +
    1. 0–2 min / Listen. Press Play, then Next and Previous. Find the main current pointer in the lab.
    2. 2–4 min / Append. Add a track, optionally with local audio. Inspect the old tail and the new node’s links.
    3. 4–6 min / Unlink. Delete a middle node, then the current, head, and tail. C chooses next, then previous, then NULL for a deleted current.
    4. 6–8 min / Rewire. Reverse A: links swap, but the current ID stays. Merge B into A: nodes transfer without being copied.
    5. 8–10 min / Boundaries. Empty a list, try an endpoint, and reset. Discuss O(1) append/navigation/merge versus O(n) search/delete/reverse.
